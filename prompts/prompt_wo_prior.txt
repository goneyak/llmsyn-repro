# Legacy reference — superseded by demographics.txt

This file was the original single-step demographics prompt used before the
pipeline was refactored into the current 4-step chain.

The active prompt templates are:
  prompts/demographics.txt   — Step 1: patient demographics (prior_note controls variant)
  prompts/diagnosis.txt      — Step 2: ICD-9 main diagnosis
  prompts/complications.txt  — Step 3: comorbidities
  prompts/procedures.txt     — Step 4: ICD-9 procedures

See src/generation/generate_variants.py for how these templates are loaded
and assembled at runtime.
